# 武林地圖 — 디자인 의사결정 이력

> 2026-05-14 하루 만의 브레인스토밍·시도·되돌리기 기록.
> 각 결정의 *이유*를 남겨 두어 미래에 같은 곳을 다시 파지 않도록 한다.

## 1. 데이터 방향 전환 — 옛 무림 → 한국 신무협

### 시작점
처음에는 김용 소설 기준 "옛 무림" 30개로 시작.
- 구파일방·5대세가(황보 포함)·일월신교(광명정)·천마신교(흑목애)·서장 밀종·새외 등
- 파일: `data/archive/factions-classic-v1.yaml` (보존)

### 전환 사유
사용자: "2020년대 이후 한국에서 유명해진 무림 웹소설 기반 웹툰들의 설정을 따라갔으면 좋겠어."

### 자료 수집
나무위키 + 작가 커뮤니티(fanmooz·postype·디씨·펨코) 종합. 핵심 발견:
- **신주오패**가 한국 무협 사파의 표준 (나무위키 공식 명시)
- **십만대산 = 신강 천산**이 다수 무협의 관습 (실제 지명은 광서·광동이지만 옛 무협이 이름을 빌려와 신강에 두는 게 굳었음)
- **해남파**가 한국 신무협 구파일방에 새로 편입 (옛 무림엔 없음)
- **오대세가**는 명칭은 "오대"지만 풀은 실제로 6개 (남궁·당·팽·제갈·모용·황보) — 작가가 5개 골라 씀

### 결과 (v2 — 34개)
- 정파 11 (구파일방 + 해남) + 세가 6 (실제 6, 명칭은 오대세가) + 사파 5 (신주오패) + 세외 7 (화산귀환 5궁 + 일반 무협 2개) + 마교 1 + 관 3 + 기타 1

### 빼기로 한 것
- 마교 내부 직제 (12장로·6대종파·칠대비궁) — 작품마다 천차만별, "세력-위치"만 다루기로
- 사도련 본단 — 작품별 위치 모호
- 광마회귀의 제천맹·제자백가 — 화산귀환·나노마신과 호환성 약함

## 2. 지도 베이스 타일 탐색

같은 데이터에 여러 베이스를 시도한 과정 (모두 무료, 인증 불필요만 후보).

| 시도 | 평가 |
|------|------|
| MapLibre demo vector tiles | 라벨 영문, 무협 분위기 약함 — 초기 프로토타입용 |
| OSM raster | 자연색, 지형 디테일 OK. **영문 도시 라벨이 분위기를 깸** |
| CartoDB Voyager NoLabels | 라벨 없음. 그러나 도시용 베이스라 **자연 지형 표현이 흐림** |
| Esri World Shaded Relief (강한 hillshade 추가) | 중국 OK, **외곽(시베리아·인도·동남아) 흐림** |
| 종이색 단색 + Natural Earth ocean GeoJSON + hillshade만 | 사용자: "이건 아니야" |
| OSM raster (롤백) | 영문 라벨 다시 등장, 결정 안 됨 |
| OpenTopoMap (등고선 baked) | 등고선 좋지만 **여전히 안 보인다고 평가** |
| **Esri World Shaded Relief 단독 + sepia + hillshade 없음** ✓ | **정착** |

### 핵심 교훈
- DEM hillshade를 직접 깔면 음영은 통제되지만 **베이스 자체에 음영이 baked된 raster가 색감 일관성이 더 좋음**
- 외곽 지역(시베리아·인도)이 흐린 문제는 **무협의 무대가 중원 중심이라 결국 받아들이는 게 자연스럽다**
- "보여주기"의 문제는 결국 사용자가 "어디까지 또렷이 보고 싶은가"의 합의 문제. Esri Shaded Relief는 중국이 또렷하고 외곽은 옅게 사라지는데, 이게 종이지도의 자연스러운 외곽 fade와 맞물려 분위기에 적합.

### 사용 안 한 후보 (라이센스/인증 이슈)
- Stadia Stamen Terrain (API 키 필요)
- MapTiler Outdoor (API 키)
- Mapbox (요금)

## 3. 시점(pitch) 탐색

### 시도 순서
1. **pitch 40° + setTerrain exaggeration 1.4** — 사용자: "너무 기울어져 있다"
2. **pitch 20° + terrain exaggeration 1.0** — 평면에 가까운 살짝 입체
3. **pitch 0° (평면) + hillshade 강화** — 정착

### 교훈
- "2.5D 느낌"이라는 요구는 실제로는 *살짝의 입체감*이지 *오블리크 카메라*가 아니었다.
- 종이지도는 평면이 정석. 입체감은 hillshade/등고선이 담당.
- terrain 3D 융기는 무겁고 sepia 필터와 어울리지 않는다 (canvas 합성이 어색).

## 4. 권역 라벨

### v1 시도
- 한자 + 한글 병기 (`中原 / 중원`)
- 큰 한자 위 + 작은 한글 아래
- 28px 한자 + 10px 한글

### v2 결정
사용자: "한자로 된 권역 라벨은 한국어로 변경하자."
- 한글만, 24px, letter-spacing 10px, opacity 0.45
- 12개: 중원·강남·파촉·영남·새북·서역·서장·남만·북해·요동·천축·대막

### 교훈
- 한자 + 한글 병기는 정보량은 많지만 시각적으로 빽빽해진다.
- 한글만 letter-spacing 넓혀도 도장(篆刻) 분위기 충분.

## 5. 정보 패널 슬림화

### v1
- 무공 / 대표 인물 / 등장 작품 / 본거지 / notes / sources

### v2
사용자: "일단 세력 내부 세부 정보는 빼고, '세력 - 위치' 정보만 수집하자."
- **본거지 + notes만 표시**
- 데이터 스키마에서도 무공·인물·작품 필드 제거

### 교훈
- 첫 버전은 욕심내서 채우면 데이터 채우기가 부담이 되고 작품별 정합성도 안 맞는다.
- "위치 기반 지도"의 핵심 가치는 **세력의 지리적 분포**다. 디테일은 v2 이후 단계적으로.

## 6. 비교 페이지 도입

베이스 타일 결정이 오래 길어져서, **6개 베이스를 2×3 그리드로 동시에 보고 마우스 sync**하는 비교 페이지를 만들었다.
- 토글: sepia / hillshade / 마커
- 결과: 5분 만에 사용자가 "Esri Shaded Relief + sepia + hillshade 없이"로 결정

### 교훈
- 디자인 결정이 길어질 때는 **A/B 비교보다 동시 그리드**가 빠르다.
- 변수 하나만 바꾸는 토글이 있으면 (sepia/hillshade/마커) 어떤 요소가 결정적인지 분리 가능.

## 7. 미해결 / 미래 후보

- 베이스 외곽 흐림 → Natural Earth land/ocean polygon으로 보강 가능
- 작품 모드 토글 (`appears_in` 필드 활용)
- 마커 클러스터링 (북경 3개·항주 2개 겹침)
- 동적 카메라 (`flyTo` + 일시적 pitch 30°로 지역 보기)
- 마교 내부 세분화 (12장로·6대종파 등 작품별 디테일)
