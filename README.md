# 武林地圖 — 한국 신무협 세력 지도

2020년대 한국 무협 웹소설·웹툰(화산귀환·나노마신·광마회귀·망나니 소교주로 환생했다 등)에서
공통으로 등장하는 세력 34개의 본거지를 종이지도 풍 인터랙티브 지도로 표시한다.

## 실행

```bash
npm install
npm run dev
```

- 메인: http://127.0.0.1:5180/
- 베이스 비교: http://127.0.0.1:5180/compare.html

## 기술 스택

| 영역 | 기술 |
|------|------|
| 빌드 | Vite 5 + TypeScript |
| 지도 | MapLibre GL JS 4 |
| 데이터 | YAML (`js-yaml` 로드) |
| 베이스 타일 | Esri World Shaded Relief (무료, 인증 불필요) |
| 필터 | CSS `sepia(0.35) saturate(0.9) brightness(1.02) contrast(1.05)` |

## 기능

### 메인 페이지 (`/`)
- 종이지도 톤 베이스 + 34개 세력 마커
- **카테고리 색**으로 분류, **마커 테두리**로 좌표 신뢰도 표시 (실선 = high/medium, 점선 = low)
- **카테고리 필터** 토글 (사이드바)
- **마커 클릭** → 사이드바에 본거지·notes 정보, 지도에 팝업
- **권역 라벨** 12개 배경에 떠 있음 (중원·강남·파촉·영남·새북·서역·서장·남만·북해·요동·천축·대막)

### 비교 페이지 (`/compare.html`)
- 6개 베이스 타일을 2×3 그리드로 동시 표시
- 마우스로 한 지도 움직이면 6개 모두 sync
- 토글: sepia / hillshade / 마커
